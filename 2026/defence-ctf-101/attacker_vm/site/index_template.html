Your service is running in the service-vm (frontend on port 67, backend on port 6767). SSH in to investigate and patch it:

ssh root@localhost -p 2222

Keep your sources under version control. If things go really wrong, there is an emergency backup of the original source in the VM:

tar xzf ~/registry-backup.tar.gz

After patching, rebuild and restart the service from inside the VM:

docker compose build && docker compose up -d
